Suzerain 汉化安装器（带窗口，可选择安装内容，可回退）
================================================================

一、这是什么
------------
一个带图形界面的安装器：把同一批汉化包（主汉化包、地图中文标注包、战争教程图片包、场景界面包、
程序内文案包、程序内单词包）列在一个窗口里，你勾选想要的，点「安装所选」；不想要了，点「还原所选」或「全部还原」。

它不重新写一套安装逻辑。每个组件的安装 / 还原，调用的是那个组件文件夹里自带的 install.ps1 / restore.ps1：
  - 校验游戏版本（catalog.hash、build-guid）和每个要替换的文件的哈希，对不上就拒绝，什么也不改；
  - 先把要替换的文件备份到「游戏目录\_patch_backup」，备份校验无误才覆盖；
  - 覆盖后再校验一遍；
  - 还原时只处理「现在正好是本组件补丁版」的文件，别的文件（别的补丁、Steam 更新后的新文件）一律不碰。
安装器本身只做四件事：找到游戏、判断每个组件现在是什么状态、排好顺序（自动补上依赖）、把输出显示出来。
安装器从不使用 -Force，所以这些安全检查在窗口里没有办法被绕过。

二、文件夹怎么放
----------------
安装器会在下面三个地方找汉化包（文件夹名以 Suzerain_CN_Plus_ 开头、里面有 patch_manifest.json /
install.ps1 / restore.ps1 的文件夹）：
  1. 本文件夹下的 packs 子文件夹
  2. 本文件夹自己
  3. 本文件夹的上一级文件夹
最省事的放法：把 6 个汉化包的文件夹和本安装器文件夹放在同一个父文件夹里（现在的工作文件夹就是这样），
或者把汉化包文件夹放进本文件夹的 packs 子文件夹。如果拿到的是 .zip，先全部解压出来再用（不要在压缩包预览里直接双击）。
窗口右下角会显示「找到 N 个组件」。只放了其中几个包也行，窗口里只列出找到的。

三、使用步骤
------------
  1. 完全退出游戏（运行中替换文件可能失败或损坏；安装器检测到 Suzerain 进程会拒绝操作）。
  2. 双击「启动安装器.bat」。
  3. 「游戏目录」会自动填成 Steam 里的 Suzerain；找不到就点「浏览…」选含有 Suzerain.exe 的文件夹。
     目录下面一行是版本检查：绿色表示和补丁一致；红色表示游戏被 Steam 更新过，补丁不适用，安装 / 还原按钮都会拒绝。
  4. 在列表里勾选要安装的组件。第一次建议只勾「主汉化包」。
     「推荐组合」= 主汉化包 + 地图中文标注包 + 战争教程图片包（三个风险低的）。
  5. 点「安装所选」，确认框里会列出实际的安装顺序（需要先装的依赖会自动加进来并标注），点「是」。
  6. 进游戏看效果、读一次档。没问题再回来装别的；有问题就回来还原（见下一节）。

四、回退（还原）
----------------
  - 「还原所选」：勾选哪个，还原哪个。叠在它上面的组件会先被自动还原（确认框里会标注「自动加入」）。
  - 「全部还原」：把所有已安装的组件按相反顺序还原，游戏文件回到安装前的样子。
  - 还原的来源是安装时的备份：游戏目录\_patch_backup\<组件代号>_<时间>\ 。备份不会被安装器删除。
    组件代号：plus（主汉化包）、maplabels（地图中文标注包）、tutorialimg、sceneui、programtext、programwords。
  - 重复「安装 → 还原 → 安装」会产生多份备份，每份大小等于被替换的文件（主汉化包约 205 MB，地图标注包约 194 MB，
    场景界面包约 34 MB，程序内文案包和程序内单词包各约 17 MB（改的是同一个文件），教程图片包约 2 MB）。「全部还原」之后游戏文件已是原版，
    整个 _patch_backup 文件夹可以删掉；还没全部还原时，不要手动删里面的东西。
  - 最后的退路：Steam → Suzerain → 属性 → 已安装文件 → 验证游戏文件的完整性。会把所有被改过的文件换回原版
    （我们的补丁也就都没了，之后在安装器里重新安装即可）。

五、各个组件
------------
  主汉化包            风险低  258 个文件  约 205 MB   对白、实体库（典籍、新闻、地图图标、决议、报告）、成就、战争条目等
  地图中文标注包      风险低  33 个文件   约 194 MB   48 张地图 / 地名贴图旁边加中文标注；必须建立在主汉化包之上
                      （其中 2 个文件与主汉化包是同一个文件，安装时会自动先装主汉化包，还原时会自动先还原它）
  战争教程图片包      风险低  11 个文件   约 2 MB     战争教程截图换成中文版
  场景界面包          风险中  3 个文件    约 34 MB    主菜单、设置、存档、战争界面等 835 个界面字符串。
                      改的是场景文件；旧汉化包曾因改场景文件在读档时闪退，原因不明。本包只改字符串；
                      作者在自己的一台机器上装着它启动游戏 7 次，每次都读档进入游戏，没有闪退（里齐亚战争界面没有检查）。
                      建议单独安装，进游戏读一次档，再决定留不留。
  程序内文案包（实验） 风险高  1 个文件    约 17 MB    编译进程序的 144 条文案（确认弹窗、存档提示、屏幕通知等）。
                      改的是程序自带字符串表，做错游戏可能无法启动（可还原）。作者在自己的一台机器上测过启动、读档和主要界面，
                      只逐条确认了其中少数条目的显示。
  程序内单词包（实验） 风险高  1 个文件    约 17 MB    17 个零散单词（弹窗按钮「是 / 否」、面板「首都 / 政府 / 人口」等）。
                      必须建立在程序内文案包之上（同一个文件，安装时会自动先装它，还原时会自动先还原本包）。
                      这些词被程序里所有用到它的地方共用；程序里若有拿它做比较的用法就会失灵（实测没有发现，但没法保证）。

列表里的「状态」含义：
  已安装 / 未安装 / 部分安装（n/m）          —— 字面意思；部分安装时再点一次安装即可补齐。
  未安装（需先装主汉化包）                  —— 地图中文标注包会显示这一条，装它时会自动先装主汉化包；程序内单词包同理，显示「需先装程序内文案包」。
  检测到旧版汉化包（可覆盖升级）            —— 游戏里是旧版汉化包的文件，新包可以覆盖它。
  文件与预期不符（n 个）                    —— 文件既不是原版也不是已知补丁（别的补丁改过，或游戏更新了）。安装器拒绝覆盖。
  游戏文件缺失（n 个）                      —— 要改的文件不存在，游戏文件不完整。
遇到「文件与预期不符」：用 Steam 的「验证游戏文件的完整性」把文件换回原版，然后回来重装。
（旧版汉化包 Suzerain_CN_Stable_… 装过的游戏不会出现这个状态：主汉化包能直接覆盖它。）

六、常见问题
------------
  Q 双击后没有窗口。
    运行「启动安装器（调试，显示控制台）.bat」，错误会显示在黑色窗口里。日志文件在
    %LOCALAPPDATA%\SuzerainCN_Installer\logs\（窗口里「打开日志文件夹」按钮也能打开），请带着日志找我。
  Q 提示「没有找到任何汉化包」。
    汉化包文件夹没放在第二节说的三个位置之一。
  Q 日志里出现「拒绝访问 / Access denied」。
    游戏装在需要管理员权限的位置时才会出现。右键「启动安装器.bat」→ 以管理员身份运行。
  Q 窗口里的日志为什么不显示每个文件。
    主汉化包要处理 258 个文件，窗口只显示进度和汇总；逐个文件的明细都写在日志文件里。
  Q 安装中途能关窗口吗？
    不能：关闭会被拦住，等它做完。真的强行结束了进程，已经启动的那一步脚本通常还会自己做完；之后重新打开安装器，
    看状态：「部分安装」就再点一次安装补齐，或者点还原。
  Q Steam 更新游戏后。
    补丁会被拒绝（版本检查变红）。更新后需要等汉化包出针对新版本的重新打包；不要强行安装。

七、测试情况（没有隐瞒）
------------------------
1. 沙盒测试（在游戏文件的拷贝里做，不碰真游戏）：对 6 个组件做了安装 / 还原的全流程，每一步之后逐个比对全部 304 个文件的哈希，
结果都和预期一致：
  - 单装地图标注包 → 自动先装主汉化包；还原主汉化包 → 自动先还原地图标注包；全装、全还原、只还原地图标注包
    （共享文件回到主汉化包的版本，而不是原版）、重复安装；
  - 程序内单词包同理：单装 → 自动先装程序内文案包；还原程序内文案包 → 自动先还原单词包；只还原单词包
    （文件回到「只装了程序内文案包」的版本）；
  - 文件被改坏 / 缺失 / 游戏版本不符 → 一律拒绝，什么都不改；
  - 装了旧版汉化包的游戏 → 主汉化包能覆盖安装，并且还原后回到旧版汉化包的文件；
  - 半装状态（少一个文件）→ 识别为「部分安装」，再安装能补齐；
  - 窗口本身：用真实窗口、真实弹窗点击完整走了一遍（推荐组合安装、安装中途关窗口被拦住、全部还原）。
2. 真实游戏实测（2026-10-12，作者自己的一台机器，Windows 11，Steam 版 3.1.0 Build 175，用作者自己的存档）。
各组件的详细情况见各自文件夹里的 README.txt，这里只列在游戏里亲眼看到的：
  - 主汉化包：从「继续」和读取窗口读档进入游戏，点过几段对白，百科、新闻、日志、笔记、国家 / 城市信息面板显示为中文；
  - 地图中文标注包：索德兰及周边的主地图上，英文地名旁边有中文标注；
  - 场景界面包：主菜单、设置页、制作人员名单、读取窗口、暂停菜单和各个面板显示为中文；装着它启动游戏 7 次，每次都读档进入游戏，没有闪退；
  - 程序内文案包：确认弹窗正文（退出到桌面 / 返回主菜单）、「继续」栏、读取窗口、面板标签显示为中文；
  - 程序内单词包：弹窗按钮显示为「否 / 是」且点击行为正确；设置页的窗口模式 / 帧率取值显示为中文，设置保存后重启仍然保留；
  - 这些运行的游戏日志里没有发现与补丁相关的异常（有几条与汉化无关的提示，例如首次启动时找不到 playersettings.dat）。
3. 没有测过的：
  新开一局、成就界面、里齐亚章节和战争界面（所以战争教程图片包的图片从没在游戏里看到过）、手动存档、
  窗口 / 无边框模式的「应用」按钮。只在一台机器、一个游戏版本、一份存档上测过，其他环境的表现没有验证。
「风险」一栏的意思：风险高的两个组件（程序内文案包、程序内单词包）改的是游戏程序自带的数据，出问题的后果比换贴图严重
（游戏可能起不来，但都可以还原）。所以第一次请只装主汉化包，进游戏读档确认后再逐个加别的。

八、已知仍是英文的地方（实机截图普查）
--------------------------------------
做法：2026-10-12 的实机测试一共留下 511 张截图（17 次启动）。我用文字识别（OCR）扫了每个画面的一张，共 258 张，再对着截图逐个核对。
其中「场景界面包、程序内文案包、程序内单词包」都装着的只有两次启动（55 张画面），下面以这两次为准。
范围有限：只覆盖我打开过的画面——主菜单、设置页、读取窗口、暂停菜单，以及索德兰章节里的地图、城市 / 国家面板和弹窗。
里齐亚章节、战争界面、成就、新开一局，以及装全之后的收藏页和制作人员页，都没有打开过，里面的英文不在这份清单里。
对白、百科这类大段文字也不在这次普查范围内。

（一）能改，但这一版没改（要先在游戏里验证过，才敢放进包里）
  - 日期时间：主菜单「继续」栏的「日期：Oct 12, 2026, 3:18 PM」，以及读取窗口里每个存档旁边的日期。
    程序里有一条固定的格式串（MMM d, yyyy, h:mm tt）管着它。存档文件里记的时间用的是另一种格式，所以这条看起来只管显示。
  - 城市 / 国家弹窗上的按钮「Open City Information」「Open Country Information」。
    程序里有一条固定的格式串（Open {0} Information），City / Country 由程序运行时填进去。
    「打开城市信息」的中文其实已经在场景界面包的场景文件里（我逐个核对过），但游戏运行时又用程序里的英文把它盖掉了，
    所以只改场景文件没有用；「Open Country Information」在场景文件里根本不存在，只能靠这条格式串。
  - 收藏页和制作人员页（只在装了场景界面包、还没装程序内文案包的那次启动里看到过；装全之后没有再打开）：
    页面标题 COLLECTIONS / CREDITS、筛选项「All Story Packs」、状态字 Locked / Unlocked、名字栏 UNKNOWN、
    底部提示「Visit the store to purchase this item.」。其中「All Story Packs」和「Visit the store…」是多词整句，原本可以放进程序内文案包；
    其余是单个单词，属于单词包那一类，要先查有没有「暗号」用法。
  - 宗教饼图图例的最后一项「Others」：同样是单个单词，没有查过它有没有「暗号」用法。

（二）改不了（程序运行时现拼的，改字符串表够不着）
  - 排名后面的序数词：1st / 2nd / 4th / 6th。程序是把数字和 st / nd / rd / th 现拼在一起的。
  - 国家关系和军力的等级名：Neutral / Strong / Overwhelming / Unfriendly 等。它们来自程序里的枚举名，硬改会破坏程序按名字的查找。
  - 读取窗口里的存档名「Turn 5」和存档类型「Turn Save」。存档名是写在你存档文件里的，已有的存档不会变。
    另外，装着程序内文案包期间新建的存档，名字很可能被存成中文的「第 N 回合」（没有验证过，说明见程序内文案包 README 的“没验证到的部分”）。

（三）故意没改
  - 设置页下拉框的取值 On / Off / High / Default：原因见程序内单词包的 README。
  - 国家 / 城市面板里民族、宗教饼图图例的名称（Dastnurity、Wruhecism、Golcondism 等）：译成中文会让地图界面整体消失，
    原因见主汉化包 README 的修订记录。

（四）不属于文案
  - 主菜单（以及设置、读取等页面）背景里那张装饰地图上的地名：是图片里的字。地图中文标注包给其中大部分补了中文，没补到的仍是英文。
  - 报纸标签页上的刊名和报头（Ekonomists、Radical 等）、背景里报纸上的字：在场景、数据库和程序字符串表里都找不到，是图片里的字。
  - 游戏标志（SUZERAIN、Torpor Games）、右下角的版本号「3.1.0 (Windows) Build: 175」、缩写 GDP / SSAO。

九、命令行（给高级用户 / 测试用）
--------------------------------
  powershell -ExecutionPolicy Bypass -File Installer.ps1 -GameRoot "D:\...\Suzerain" -PacksRoot "D:\...\packs"
    -GameRoot / -PacksRoot 可以省略。
  powershell -ExecutionPolicy Bypass -File Installer.ps1 -Headless -GameRoot "..." -Scenario "install:maplabels;status" -Yes
    不开窗口，按步骤执行：install:<组件代号,...|*>、restore:<...>、restoreall、status；不加 -Yes 只显示计划不执行。
    组件代号：plus、maplabels、tutorialimg、sceneui、programtext、programwords。
